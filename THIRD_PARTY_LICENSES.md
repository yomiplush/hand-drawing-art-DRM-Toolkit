## Web & PWA Runtime Dependencies

All frontend runtime dependencies are open-source and bundled locally with zero external CDN requests:

| Package | Purpose | License |
| --- | --- | --- |
| `react` / `react-dom` | UI rendering | MIT |
| `react-router-dom` | Client-side SPA routing | MIT |
| `@noble/ed25519` | Audited pure-TS Ed25519 signatures & fallback | MIT |
| `@noble/hashes` | Audited SHA-256 / SHA-512 primitives | MIT |
| `@yomiplush/chm-exchange` | Local CHM-Exchange key packet helper | MIT |
| `cborg` | Deterministic RFC 8949 CBOR codec | MIT / Apache-2.0 |
| `fast-png` | Lossless PNG decoder/encoder (no premultiplied alpha loss) | MIT |
| `qrcode` | Local QR matrix generator | MIT |
| `jsqr` | Local QR decoder | Apache-2.0 |
| `lucide-react` | Bundled vector icons | ISC |

## Standalone Edition Launcher

The Portable Standalone Edition launcher (`standalone/`) is written in **pure Go using only the Go standard library** (BSD-3-Clause Go runtime) with **zero third-party Go modules**.
